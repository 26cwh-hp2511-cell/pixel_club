## Day Dreamer

A one-button rhythm platformer. Open `index.html` in a desktop browser, then use **Space**, **W**, or **Up Arrow** to jump and restart.

- Stage: **Day Dreamer**
- Difficulty: **6 / 10**
- The project contains no copyrighted audio. Play alongside an authorized copy of the referenced track.
